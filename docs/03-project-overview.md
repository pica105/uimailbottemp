# MailHub — Обзор проекта

## Что это

**MailHub** — Telegram-бот для работы с почтой Gmail и Яндекс прямо в Telegram. Подключение через OAuth, уведомления о новых письмах в чат, полный инбокс в Mini App (без установки приложений). Бот и Mini App — один проект, два компонента: Python-бекенд (aiogram + aiohttp + SQLite) и Next.js-фронтенд.

## Как это работает

### 1. Подключение аккаунта
1. `/start` → выбор языка (ru/en) → пользователь создаётся в БД
2. `/accounts` → «Подключить Gmail/Яндекс» → бот шлёт OAuth-ссылку
3. Авторизация в браузере → колбэк `{BASE_URL}/oauth/{provider}/callback`
4. Обмен code → tokens, шифрование Fernet, сохранение в БД
5. Первый импорт 50 последних писем — **без** флуда уведомлений (`mark_all_notified`)

### 2. Синхронизация (движок)
1. Каждые `SYNC_BASE_INTERVAL_SECONDS` (5 с) движок проходит активные аккаунты
2. Gmail — REST `users.history` от checkpoint'а; Яндекс — IMAP UID-инкремент
3. Новые письма → кэш в SQLite + уведомление в Telegram (кроме muted-категорий)
4. **Эластичный интервал на аккаунт:** свежее письмо → 10 с, тихий ящик → до 5 мин (`max(10с, min(потолок, простой/10))`); ошибки — экспоненциальный бэкофф

### 3. Просмотр и действия (Mini App)
1. Кнопка «Открыть в MailHub» → Mini App (initData-аутентификация на каждый запрос)
2. Inbox: категории All/Important/Promo/Spam, аккаунты, просмотр письма
3. «Прочитано»: оптимистично в UI + прокидывание в ящик (Gmail `modify`, Яндекс `\Seen`)

### 4. Настройки
- `/settings` в боте и в Mini App: язык, muted-категории. Интервал синхронизации — полностью автоматический (эластичный 10с–5мин), ручной выбор отсутствует
- `/accounts`: список, удаление (токены из БД удаляются)
